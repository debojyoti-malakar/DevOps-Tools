##  Git

**Purpose:** Git is a distributed version control system used to track changes in source code.

**Official Website:** [Git](https://git-scm.com/)

**Common Command:**

```bash
git status
```

##  Docker

**Purpose:** Docker is a platform used to build, package, and run applications in containers.

**Official Website:** [Docker](https://www.docker.com/)

**Common Command:**

```bash
docker --version
```

![Docker](https://img.shields.io/badge/Docker-2496ED?logo=docker&logoColor=white)

##  Jenkins

**Purpose:** Jenkins is an automation server used for building, testing, and deploying software.

**Official Website:** [Jenkins](https://www.jenkins.io/)

**Common Command:**

```bash
java -jar jenkins.war
```
